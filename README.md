# Sales-persons-dashboard
**1. PROJECT TITLE :** 

Sales Data Analysis Dashboard using Power BI

**EXAMPLE:**

An interactive Power BI dashboard developed to analyze and visualize sales data, track key performance indicators (KPIs), identify revenue trends, and evaluate product and regional performance. The dashboard enables quick, data-driven decision-making through dynamic filters, clear visualizations, and real-time insights.


**2. SHORT DESCRIPTION / PURPOSE**

**Description:**

This project focuses on analyzing historical sales data to identify key business insights such as revenue trends, top-performing products, and sales performance across regions and time periods.
**Purpose:**

The main objective is to help stakeholders make data-driven decisions by visualizing sales KPIs, identifying growth opportunities, and tracking performance through an interactive Power BI dashboard.
**Example Statement:**

Designed an interactive Power BI dashboard to analyze sales performance, uncover revenue trends, and support strategic decision-making.


**3. TECH STACK**

**Tools & Technologies Used:**

**Power BI** – Data visualization & dashboard creation
**Microsoft Excel** – Data cleaning and preprocessing
**SQL** – Data querying and transformation
**DAX** – Calculated measures and KPIs

**Example:**

The project was built using Power BI for visualization, Excel and SQL for data preparation, and DAX for advanced calculations.


**4. DATA SOURCE**

**Data Description:**
The dataset consists of structured sales records including:
Order ID
Order Date
Product Category & Product Name
Sales Amount
Quantity Sold
Region / Location
Customer Segment
Source Type:
CSV / Excel sales dataset (simulated business data)
**Example:**

Sales data was sourced from Excel files containing transactional sales records across multiple regions and product categories.


**5. FEATURES / HIGHLIGHTS:**

**✅ Key Features:**

📊 KPI Cards – Total Sales, Total Orders, Profit, Average Sales
📈 Time-Series Analysis – Monthly and yearly sales trends
🏆 Top Products Analysis – Best-performing products and categories
🌍 Regional Performance – Sales distribution by region
🎯 Interactive Filters – Slicers for date, region, and category
⚡ Dynamic DAX Measures – Real-time calculations and insights

**Example Highlight Statement:**

The dashboard provides real-time insights with interactive slicers, KPI tracking, and trend analysis to quickly identify business patterns.
